Koperasi Suzuki Mart - POS Product Illustrations
===============================================

Total: 30 SVG files (6 illustrations x 5 categories).

Naming:
  minuman-illustration-{n}.svg
  makanan-illustration-{n}.svg
  sembako-illustration-{n}.svg
  rumah-tangga-illustration-{n}.svg
  lainnya-illustration-{n}.svg

Catatan teknis:
- Sumber ilustrasi awal berupa PNG/raster.
- File SVG ini membungkus crop PNG secara embedded/base64, sehingga portable
  dan bisa langsung dipakai sebagai <img> di aplikasi tanpa file PNG terpisah.
- Visual tetap identik dengan ilustrasi sumber, tetapi ini bukan hasil vector-tracing.
- Canvas SVG diseragamkan ke 420x400 untuk konsistensi pada product card POS.

Lihat manifest.csv untuk mapping nama file ke jenis ilustrasi.
