## 3. Classification vocabulary

Operation type (PRD §3.1): **R** read · **C** create · **U** update · **D** delete · **Ap** approve · **Rj** reject · **Ca** cancel · **Rv** reverse · **Im** import · **Ex** export · **Ca**lc calculate · **Rc** reconcile · **O** other.
New-app status: **Existing** (built read-only in Next.js), **Partial** (some read or one channel built), **Missing**. Priority P0/P1/P2/P3 per [09](09_IMPLEMENTATION_BACKLOG.md); **RETIRE** = not migrated (reason given); **HOLD** = waiting for a consumer decision.
Authorization column: legacy gate is per controller (`user_m::cekstatushakakses`, `models/user_m.php:379`) — every method of a reachable controller is callable by anyone who can open its page (`ANO-K02`). It is written "page gate" below.
Transaction column: "none" means each statement auto-commits; a failure part-way leaves earlier statements committed.
