# 06 — PWA strategy

## Manifest (`src/app/manifest.ts` → `/manifest.webmanifest`)

`name` "S-MART KKISI TB2 — Anggota", `short_name` "S-MART TB2", `id` and `scope` `/`, `start_url` `/beranda?source=pwa`, `display` standalone, portrait, `lang` id-ID, white theme/background (matches the white app bar), shortcuts to Simpanan, Pinjaman, Belanja. Icons generated by `scripts/generate-icons.mjs` from the approved emblem (`apps/web/public/illustrations/kopkar-emblem.png`): 192 and 512 px `any`, 192 and 512 px `maskable` (emblem inside the 72 % safe zone), 180 px apple-touch-icon, 32 px favicon. The header logo is extracted from the approved mockup itself.

## Service worker (`/sw.js`, source in `src/lib/pwa/service-worker-source.ts`)

No plugin: the worker is generated by a route from a template plus the `classifyRequest` function in `src/lib/pwa/cache-policy.js`, embedded with `Function.prototype.toString` — the unit tests import the very same function.

| Request | Strategy | Stored? |
|---|---|---|
| `/_next/static/*` (content-hashed) | cache first | yes, versioned cache, max 150 entries |
| `/icons/*`, `/images/*`, `/offline.html`, `/manifest.webmanifest` | cache first | yes |
| Page navigations (all member pages, `/masuk`, `/pin`) | network only; on network failure the precached `/offline.html` | **never** |
| RSC payloads (`RSC: 1` header or `_rsc` query) | not handled by the worker | **never** |
| `/api/*` (auth, prices) | not handled | **never** |
| non-GET, other origins | not handled | — |

Additional guards: a response is stored only if it is `ok`, same-origin `basic`, and its `Cache-Control` has neither `no-store` nor `private` (every member response has both). Member pages also carry `Cache-Control: private, no-store` for the HTTP cache. Logout sends `Clear-Site-Data: "cache"`. The E2E suite inspects Cache Storage after browsing member screens and fails on any URL outside the public allow-list.

## Offline behaviour

* Navigation while offline → `offline.html`: explains that member data requires a connection and that no stale balances are shown; "Coba lagi" button; reloads itself when the `online` event fires (E2E verifies the same URL becomes the live screen again).
* In-app: a sticky banner "Kamu sedang offline…" (`PwaRuntime`); failed sections render "belum dapat dimuat" with a retry; nothing is ever replaced with zero.
* No offline submission exists (no write flows are enabled).

## Installation

* Android/Chromium: `beforeinstallprompt` is captured; Beranda shows a dismissible "Pasang S-MART TB2" card (dismissal remembered 30 days); Lainnya → "Pasang aplikasi" is always available.
* iOS Safari (no `beforeinstallprompt`): the same entry points open a sheet with "Bagikan → Tambah ke Layar Utama" steps; `appleWebApp` metadata and apple-touch-icon are set.
* Already installed (`display-mode: standalone` / `navigator.standalone`): prompts hidden.
* Installability needs HTTPS: `app.kkisitb2.id` must be served over TLS (08).

## Update lifecycle

1. `register('/sw.js', { updateViaCache: 'none' })`; the route sends `Cache-Control: no-cache, no-store` and nginx repeats it.
2. Checks for a new version when the app returns to the foreground and hourly.
3. A new build gets a new cache name (`kkisi-static-<version>-<build>`); the new worker installs and **waits**.
4. The member sees "Versi baru aplikasi tersedia — Muat ulang". Only that click sends `SKIP_WAITING`; the page reloads on `controllerchange` only when the member asked (the first-install `clients.claim()` must not reload — a bug found by E2E and fixed).
5. On activation the worker deletes every older `kkisi-*` cache, so no stale bundle survives.

## Content Security Policy

`default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob:; font-src 'self'; connect-src 'self'; worker-src 'self'; manifest-src 'self'; frame-ancestors 'none'; base-uri 'self'; form-action 'self'`. `'unsafe-inline'` is needed by Next's inline bootstrap scripts; tightening it requires a nonce-issuing proxy (follow-up, low priority because no third-party script is loaded and all output is React-escaped). The service worker itself is served with `script-src 'self'`.

## Future capabilities
