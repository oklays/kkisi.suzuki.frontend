# 07 — Legacy Anomaly Register (Import/Export)

Nothing in this register was fixed. Each entry describes legacy behaviour that KOSIPA New **must not copy blindly**. IDs use the prefix `IE-ANO-` so they do not clash with the earlier `ANO-K01…K50`, `ANO-X`, `ANO-G` registers. Related earlier IDs are cross-referenced.

**Evidence levels**
- **Static:** source read.
- **Runtime-probe:** reproduced with a synthetic file in a network-isolated PHP container. The probe used the legacy Spout library, mounted read-only, and no database (see [AUDIT_EVIDENCE_AND_COVERAGE.md §4](AUDIT_EVIDENCE_AND_COVERAGE.md#4-safe-runtime-tests)).
- **Observed-data:** read-only, count-only queries on the 30 Oct 2026 data copy. The data is consistent with the cause, but does not by itself prove it.

**Security-sensitive entries** list only what is needed to act. Paths, filename patterns and reproduction steps are in the gitignored `docs/superpowers/specs/kosipa-full-access/private-legacy-security-findings.md` (section "Import/Export audit, 8 Nov 2026").
